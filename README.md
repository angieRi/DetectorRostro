# DetectorRostro
Ejm de detector de rostos en tiempo real con  python, opencv, mediapipe 

## 📦 Librerías utilizadas

- [OpenCV](https://opencv.org/) – Para el procesamiento de imágenes y manejo de cámara.
- [MediaPipe - Face Detection](https://google.github.io/mediapipe/solutions/face_detection.html) – Para la detección de rostros en tiempo real.
